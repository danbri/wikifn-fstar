Project overview

Best Current Demo

Z22294 Devanagari digits to Arabic digits is the clearest end-to-end path today. It is a real pinned Wikifunctions composition, generated into F*, checked by F*, extracted to OCaml, compiled to JavaScript, and runnable in Node or the browser.

This is the best answer to: can we already get JavaScript from a complete composed Wikifunction that uses only the supported primitive kernel? For this selected path, yes, relative to the pinned local objects and the current grounded primitives.

The current real end-to-end selected composition demos are mostly text/control functions. Numeric primitives are grounded and runnable through the playground JSON IR, but a real generated numeric Wikifunction composition has not yet been promoted as the lead demo.

Plain Terms

  • F* is the checked source language used for the core definitions.
  • OCaml is the extraction target produced from F*.
  • js_of_ocaml turns OCaml bytecode into JavaScript.
  • Z22294 and similar names are Wikifunctions object or function IDs.
  • Z7 means a Wikifunctions function call object.
