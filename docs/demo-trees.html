Composition Trees

A local D3 browser for selected composition graphs. It uses saved local data and does not contact Wikifunctions while browsing.

Demos menu

Draw A Tree

The tree marks selected compositions, arguments, constants, assumed primitives, and foreign-code frontiers. A tree is drawn only after the button is pressed.

How To Read It

  • Composition nodes are Wikifunctions implementations written as function calls.
  • Primitive leaves are current assumptions or F*-grounded leaves, depending on the selected graph.
  • Open-frontier nodes show where the selected graph reaches unsupported or foreign implementation territory.
